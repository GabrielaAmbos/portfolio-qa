Sobre mim

Sou QA Engineer com mais de 6 anos de experiência em Qualidade de Software, atuando em produtos dos setores financeiro, varejo, e-commerce, educação e games.

Ao longo da minha trajetória, trabalhei com sistemas de diferentes níveis de complexidade — de movimentações financeiras e cálculo de comissões a operações omnichannel e jogos multiplataforma. Participei de projetos para empresas como Grupo Casas Bahia, Banco Fibra, Lojas Renner, Aquiris e RedStudios, incluindo a validação multiplataforma de Horizon Chase 2 e testes Alpha/Beta de projetos da franquia V-Monsters.

Gosto de enxergar qualidade além da interface. Meu trabalho envolve entender requisitos e regras de negócio, identificar riscos, investigar o comportamento entre diferentes camadas da aplicação e transformar tudo isso em uma estratégia de testes clara e sustentável.

Principais áreas de atuação

  • Estratégia de testes: planejamento, análise de requisitos, testes baseados em risco e gestão de defeitos
  • Automação Web e E2E: Cypress, Selenium WebDriver, JavaScript, Node.js, Java e C#
  • BDD: criação de cenários em Gherkin para aproximar negócio, desenvolvimento e QA
  • API Testing: REST e SOAP com Postman, SoapUI, Rest Assured e RestSharp
  • Dados e integrações: SQL, SQL Server, DBeaver, Kafka e análise de logs
  • Mobile e multiplataforma: Android, iOS, macOS, tvOS e testes de games com Unreal Engine
  • Times internacionais: documentação técnica em inglês e experiência profissional em espanhol

Projetos de automação

Aqui estão alguns projetos que desenvolvi para praticar e demonstrar diferentes abordagens de automação de testes, desde APIs até jornadas Web E2E.

Fake Store API · Automação de API

Projeto desenvolvido para exercitar uma suíte de automação de APIs com Cypress, JavaScript e Node.js, cobrindo diferentes recursos e comportamentos da Fake Store API.

A suíte possui 40 testes automatizados, incluindo cenários positivos e negativos para produtos, carrinhos, usuários e autenticação. Também implementei validações de contratos e respostas, custom commands, fixtures, separação de testes smoke e regressivos e geração de relatórios.

O projeto utiliza GitHub Actions para execução automatizada e possui documentação em português e inglês.

Trivago · Automação Web E2E

Projeto de automação end-to-end criado sobre um ambiente real de busca de hotéis, utilizando Java, Selenium WebDriver, Cucumber e Maven.

Os cenários foram escritos em BDD/Gherkin e organizados utilizando Page Object Model, com testes para busca, ordenação e filtros. A automação também contempla execução headless, diferentes navegadores e captura automática de screenshots quando uma execução falha.

O principal desafio deste projeto foi trabalhar com uma aplicação real e seus dados dinâmicos, mantendo as validações o mais estáveis possível.

JavaSeleniumCucumberMaven

Go Rest API · Automação com RestSharp

Projeto de automação de API REST desenvolvido com C# e RestSharp, com foco na validação de respostas, contratos e status HTTP.

O objetivo foi explorar uma abordagem de API Testing utilizando o ecossistema C# e organizar os testes de maneira simples e de fácil manutenção.

O que testo em jogos

Funcionalidade

Menus, controles, progressão, interações, estados do jogo e comportamentos esperados.

Exploratório

Uso do jogo além do caminho esperado para encontrar situações não previstas.

Regressão

Validação de funcionalidades existentes após correções ou novas implementações.

Compatibilidade

Comportamentos específicos entre dispositivos e plataformas.

Usabilidade

Fluxos confusos, feedback insuficiente, dificuldade de entendimento e outros pontos que afetem a experiência.

Defeitos

Reprodução, evidências, contexto da falha, impacto e reteste após correção.
